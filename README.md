
# YouTube Comment Bot 🇵🇱

Bot do automatycznego komentowania nowych filmów z kanału YouTube.

## Instrukcja:
1. Włącz YouTube Data API v3 w Google Cloud
2. Utwórz OAuth 2.0 (Desktop app), skopiuj `CLIENT_ID` i `CLIENT_SECRET`
3. Wpisz dane jako zmienne środowiskowe w Railway
4. Railway uruchomi `python3 main.py`
5. Za pierwszym razem zaloguj się przez link OAuth (logi)
